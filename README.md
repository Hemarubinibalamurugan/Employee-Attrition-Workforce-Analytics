## Employee Attrition Workforce Analysis

## 1. Project Overview

Employee Attrition Workforce Analysis is an end-to-end data analytics project focused on understanding employee turnover patterns and identifying the factors associated with employee attrition.

## 2. Business Problem

Employee attrition can increase recruitment costs, reduce productivity, and affect workforce stability. This project analyzes employee data to understand attrition patterns and support better HR decisions.

## 3. Project Objectives

- Identify factors associated with employee attrition.
- Analyze attrition across departments and job roles.
- Understand demographic and compensation patterns.
- Examine overtime and job satisfaction.
- Analyze work-life balance.
- Generate actionable business insights.

## 4. Dataset Information

- Dataset Name: Employee Attrition Workforce Analysis
- Dataset Source: YBI Foundation Public
- Domain: HR Analytics
- Target Variable: Attrition
